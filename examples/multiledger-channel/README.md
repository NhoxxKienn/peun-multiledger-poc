# Multiledger Channel Demo (POC)

This example folder is for a direct Perun multiledger payment channel proof-of-concept.

## Intended scenario

- Two participants open one channel that references balances on multiple ledgers.
- Participants exchange off-chain state updates.
- Participants close and settle on each involved ledger.

## Planned deliverables

- Minimal runnable demo app
- Deterministic demo script (open, update, settle)
- Notes on ledger-specific setup assumptions
